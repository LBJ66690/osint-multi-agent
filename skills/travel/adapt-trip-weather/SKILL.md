# 按地点和出游日调整安排

读取日程中景区入口、县区、出游日、室内外类型、已确认的票和不可改变的时段。以 `weather.forecast` 获取实际目的地的预报，保留发布时间、有效日期和覆盖地区。首页贵阳实况供人物播报，只有行程当天也在贵阳时才作为相关地点信息使用。

1. 对每个受影响日匹配当日预报，再用 `notice.lookup` 核对同一入口、线路、日期的景区运营公告。县级预报要注明地点粒度，山顶的实时状况待景区确认。
2. 普通降雨时给游客一个能抵达的替代活动或可行的换日方案。适用的停运／关闭公告优先剔除受影响项目。预报超出窗口、过期或工具失败时记录未知，并给出临行复查入口。
3. 只改受影响活动，重算改动路段与费用。遇到改预约、加钱或放弃必去点，把选择交回游客。没有必要调整时保留原日程，写清依据。
4. 返回 `affected_days`、`changes`、`alternatives`、`recheck_items` 和 `evidence_ids`。每项调整写清原安排、替代、触发原因及所依据的预报或公告。

例：贵阳今天下雨、江口县明日预报晴，导游可在首页撑伞；梵净山行程按江口的目标日期及景区公告处理。
