# 比较从出发地到实际目的地的交通

读取出发日、起点、目的地入口、出发／到达窗口、同行人数、游客允许的方式及已购票。已有已确认的车次先作为固定条件；需要查询余票时采用此次行程的日期。

1. 铁路经 `rail.search` 先核对车站码，再查询直达；直达无法满足条件且允许换乘时再查中转。分清铜仁站和铜仁南站。仅在游客接受飞机并确有航空比较需求时调用 `flight.search`。
2. 用 `route.leg` 补接驳，用同一口径比较出门至到达景区的总时长、费用区间、最晚到达和换乘次数。计入机场或车站的合理缓冲，显示假设。每项票价注明按人还是全团、日期及查询时间，余票状态按返回值说明。
3. 剔除赶不上硬性时段的候选；在可行候选中按游客偏好比较，必要时给一个更便宜或更早到达的备选。缺报价或时长时指出比较缺口。保留售罄、未开售、接口故障与无法判断的区别。
4. 返回 `options`、`selected_or_pending`、`booking_entry`、`evidence_ids`。预订按钮指向已核验的官方或授权渠道，游客在那里确认并完成交易。

例：两班车分别到铜仁站和铜仁南站，根据「到东门」的门到门耗时排序。更早到站的车仍可能更晚抵达东门。
