# 判断预算能否承诺

读取总额、人均或全团口径、人数、房数、晚数、费用范围，以及有证据的报价或已确认金额。游客已付费用单列，并按游客指定口径决定是否计入旅行总额。

1. 逐项标记按人、按房晚、按车或按团计价，使用一致的人民币单位。区分单程／往返、套餐已含项目和必付附加费。使用整数分或 Decimal，让程序计算明细和合计。
2. 将每项标作确价、有效区间、仅起价或未知。确需补门票价格时使用 `ticket.quote`，核对票种及适用日期。途牛 `startPrice` 只能作为区间起价展示。与目标日期或票种不匹配的报价不参与该项金额计算；仅当来源确实给出该出游日可用的上限，才能用于预算上限判断。
3. 若必需项的已知下限合计已超限，给出最低超支额。若所有必需费用的上限均有依据且合计不超过限额，标「预算内」。其余情况写明风险和待查金额，避免承诺总额。提出一项能改善结果的调整并重新核算。
4. 返回 `lines`、`known_lower`、`upper_or_null`、`budget_status`、`missing_costs` 与 `evidence_ids`。未知不当作零。

例：两人同住一间，260 元／间晚、住两晚，住宿为 520 元。门票仅有「80 元起」时，不能把 80 元当作当天的封顶价。
