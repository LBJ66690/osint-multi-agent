# 开源情报多智能体研究平台

输入一个研究问题，项目会组织规划、收集、分析、推理、报告和核查岗位，生成带来源的研究报告。提供暖白色网页工作台，支持人工确认计划、手选搜索通道、查看执行进度、历史记录、断点恢复及报告追问。

## 从这里开始

第一次安装、启动或把项目交给别人使用，请阅读 **[项目启动指南](项目启动指南.md)**。指南包含环境准备、Windows 安装命令、每次启动输入 API Key、首次任务和常见错误处理。

已安装好依赖的 Windows 用户，在项目目录打开 PowerShell：

```powershell
.\.venv\Scripts\python.exe -B launch.py
```

按提示隐藏输入自己的百炼 API Key，服务就绪后浏览器会自动打开：

```text
http://127.0.0.1:8765
```

若没有使用项目虚拟环境，可以双击 `启动项目.bat`。脚本会自动选择解释器；具体优先级和注意事项见启动指南。停止服务使用 Ctrl+C，或关闭启动终端。

## 使用流程

1. 在欢迎页中央输入研究问题，在研究设置中选择深度与模型。
2. 确认研究计划，再手动选择搜索通道。
3. 在看板查看阶段、来源、证据与计时，按提示处理核查待办。
4. 完成后阅读或下载最终报告；也可选择模型，就报告继续提问。
5. 失败或超时后从历史记录打开任务，检查错误原因，再从断点继续。

提供简明解答、标准研究、深入研究三档深度。检索策略默认为稳定模式（Legacy），也可选择自适应模式（Adaptive），在已选渠道内按证据覆盖、重复情况和预算有限调整查询。界面上的模型列表不代表你的账户一定拥有对应权限或剩余额度。

## 文件说明

| 文件或目录 | 用途 |
| --- | --- |
| `启动项目.bat` / `launch.py` | Windows 启动入口 / 交互启动程序 |
| `server.py` | 网页服务、接口与任务状态 |
| `pipeline.py` / `pipeline_execution.py` | 研究编排 |
| `agents.py` / `models.py` | 模型调用与岗位配置 |
| `search_sources.py` | 搜索来源适配 |
| `static/` | 网页、样式、阶段导航和虚拟宠物 |
| `requirements.txt` | Python 依赖 |
| `.env.example` | 不含真实密钥的可选配置模板 |
| `scripts/` / `tests/` | 维护与测试代码 |
| `outputs/` | 自动生成的报告、历史、检查点和日志 |

## 密钥与费用

- 每次启动由使用者隐藏输入自己的 API Key，不应将 Key 写入源码、文档、`.env` 或 GitHub。
- 模型研究、报告追问和可选百炼搜索会使用账户额度；公开搜索通道也可能有配额、限流或网络限制。
- 本地界面、大肥鱼交互和固定数据的界面测试不会调用模型。
- 分享项目时排除 `outputs/`、`.env`、虚拟环境、日志与调试文件。项目默认仅监听本机，不应直接当作有登录鉴权的公网服务部署。

模型生成的结论需要结合引用来源核对；证据不足或核查未通过的部分应保留其不确定性。

## 自动选档与 SAG Wiki

普通模式选择「自动匹配」时，使用百炼的简明规划模型判断任务所需的深度，选择最多 1、3 或 5 个子问题。这会增加一次短模型请求。计划确认前可以上调一次，语义路由超时或失败时使用本地规则。手选深度会直接执行对应档位。

可选 SAG Wiki 补查。先为允许提供给云端模型的 Markdown 或纯文本资料建好索引。启动项目前设置 `OSINT_SAG_SCOPE` 为资料目录绝对路径，`SAG_DATA_DIR` 为包含 `sag.sqlite` 的索引目录。本项目只读 SAG Wiki 的 SQLite 结构版本 9，按已有分块与行号定位原文，并核对文件内容与索引是否一致。只对证据薄弱或存在冲突的子问题做关键词补查。报告中的本地证据链接可查看该次保存的原文片段。私人聊天记录应留在单独目录。

配置 SAG 后，打开已完成的报告，点击「保存片段到 SAG」，预览并勾选要保留的章节。片段会保存到资料目录的 `osint-report-excerpts/`，保留原 Markdown 和引用，由 SAG Wiki 自己更新索引。若页面显示等待索引，请保持 SAG Wiki 的监视服务运行。保存的报告片段可在 SAG Wiki 搜索，OSINT 的事实核查仍使用原始证据。
