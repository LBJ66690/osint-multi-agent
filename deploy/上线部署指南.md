# OSINT 平台 MySQL 上线指南

上线模式提供用户名注册及登录、个人研究记录、报告和续跑。使用 MySQL 8，中文内容以 utf8mb4 保存。研发时可以用仓库根目录的 Compose 启动独立的 Web 和 MySQL。华为云部署使用 ECS、同 VPC 的 RDS for MySQL 及 HTTPS 域名。

## 本机启动

在项目目录使用 PowerShell。为这套本机测试库生成两个独立密码，并将它们保存到密码管理器。Docker Compose 需要在每次操作时读到相同的配置。以下命令可以在项目已安装的 Docker Desktop 中执行。

```powershell
$env:OSINT_DB_ROOT_PASSWORD = [guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N')
$env:OSINT_DB_PASSWORD = [guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N')
docker compose up --build -d --wait
```

访问 [本机工作台](http://127.0.0.1:8765)，在「注册」中创建账号。用户名允许 3–32 个英数字符或下划线，密码要求 12–128 个字符。默认使用 8765，设置 OSINT_WEB_PORT 可以更换。请使用 127.0.0.1 和对应端口访问，站点会检查会话写请求的来源。未配模型时可直接验证注册、登录与历史隔离。

停止容器可用 docker compose stop。MySQL 数据保存在 osint_mysql_data 卷内，同一卷再次启动时沿用原密码。通过 docker compose logs web 查看服务启动日志。初始化 SQL 仅在新卷第一次启动时自动执行。已有卷在调整结构前先备份，按正式迁移脚本升级。

## 启用百炼模型

六个模型的额度停用日记录在 bailian_models.py，日期采用北京时间。截图只有日期，于所示日期零时停止派发新请求。可通过 OSINT_DISABLED_MODELS 提前停用个别模型，使用逗号分隔登记的模型 ID。自动岗位配置只选择当前仍启用的登记模型。请求中的模型 ID 会在送交百炼之前再次校验，收到 AllocationQuota.FreeTierOnly 后该进程也会停用该模型。

先在百炼控制台为启用的模型逐个打开「免费额度用完即停」，等设置生效，再给服务进程注入 DASHSCOPE_API_KEY 和 OSINT_BAILIAN_FREE_ONLY_CONFIRMED=1。Docker Compose 更新这两个进程变量后，执行 docker compose up -d web 重建 Web 容器。直接本机文件模式可以将确认开关填入项目 .env，密钥仍走原启动时的隐藏输入。

服务以控制台配置为扣费边界。确认环境变量只表示运维人员已操作控制台，应用无法读取账户实时额度。通用 API、编码订阅额度和搜索服务分别核对。云上模式提供公开检索渠道。

[百炼免费额度使用与用完即停说明](https://help.aliyun.com/zh/model-studio/new-free-quota)

## 华为云部署

1. 按 CodeArts 任务单，使用码道与部署 Skill 为 ECS、EIP、RDS、备份和流量列出费用估算，并记录资源规格。团队核对 IAM、配额、区域、域名和现有资源后再执行实际开通。
2. 在同一区域、同一 VPC 内配置 ECS 和 RDS for MySQL 8.0。RDS 使用私网，安全组仅允许应用所在的安全组访问数据库端口。以有建表权限的账号创建数据库并依次执行 001_initial.sql 和 002_travel.sql（已有 v1 库仅执行 002_travel.sql），然后给应用独立账号授予此库内 SELECT、INSERT、UPDATE、DELETE。
3. 从可信渠道获取 RDS CA，放入 deploy/certs，并配置 OSINT_DB_SSL_CA_IN_CONTAINER=/rds-certs/实例CA证书文件。使用与证书匹配的连接地址，开启证书与主机名校验。
4. 私密注入 OSINT_DB_HOST、OSINT_DB_USER、OSINT_DB_PASSWORD 以及模型配置。设置 OSINT_PUBLIC_ORIGIN 为网站外部的 HTTPS 源，例如 https://osint.example.com。建议邀请制试运行，可在注册开启时设置 OSINT_SIGNUP_CODE，也可在演示账号已建成后设 OSINT_REGISTRATION_ENABLED=0。
5. 在 ECS 的项目目录执行 docker compose -f deploy/compose.rds.yml up --build -d --wait。应用端口仅映射到 ECS 回环地址。配置 Nginx、证书和域名，可以从 deploy/nginx.conf.example 起步。SSE 需要关闭反向代理缓冲。当前交付使用一个 Web 副本和一个 worker，运行中的确认及续跑调度由该进程维护。
6. 上线验收使用两个测试账号。检查 HTTPS Secure 会话、登录退出、研究、SSE、报告下载与追问、另一账号访问同一任务返回 404、容器重建后能读取历史及继续已保存任务。演练数据库备份与恢复，同时记录配额失败和外部搜索超时的提示。

[华为云 RDS 官方内网连接指南](https://support.huaweicloud.com/qs-rds-mysql/rds_02_0047.html)

## 表结构与历史处理

| 表 | 用途 |
| --- | --- |
| osint_users | 用户名、Argon2id 密码摘要 |
| osint_sessions | 会话令牌的 SHA-256 摘要、过期时间和拥有者 |
| osint_rate_limits | 登录、注册及账号任务和追问次数 |
| osint_runs | 按 owner_id 归属的研究任务、状态和结果摘要 |
| osint_run_checkpoints | 断点状态、计划、证据与阶段结果 |
| osint_run_events | 按任务和 seq 存储的事件，供 SSE 和恢复回放 |
| osint_run_artifacts | 研究计划、证据产物、报告草稿和最终正文 |
| osint_report_chats | 报告内容版本对应的问答记录 |
| osint_schema_versions | 数据库结构版本 |

本机文件模式继续保留以前的 outputs 历史和 SAG 入口。开启 MySQL 时，服务器使用用户归属明确的新库，既有本机研究内容仍留在原目录。将来确需迁移旧任务时，由团队明确每项所有者和输入清单，使用独立备份验证后再导入。

## 验证命令

安装 requirements.txt 后运行 python -m unittest discover -s tests。MySQL 集成测试须使用已初始化的独立测试数据库，设 OSINT_TEST_MYSQL=1 和对应的 OSINT_DB_HOST、OSINT_DB_PORT、OSINT_DB_NAME、OSINT_DB_USER、OSINT_DB_PASSWORD。测试中模型和搜索均由固定样例代替。
