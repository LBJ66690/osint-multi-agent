# 贵州文旅静态素材来源

## 导游与地图

- 小岚的 SVG、静态 PNG 和动作是本次交付的原创插画。袖口装饰参考黔东南雷山苗绣，银色饰品为当代插画设计。[中国非遗网·苗绣](https://www.ihchina.cn/art/detail/id/13989.html)
- 阿禾的 SVG、静态 PNG 和动作是本次交付的原创插画。采用靛蓝斜襟、青白布帕和布包，参考黔西南布依族服饰，细节为当代插画设计。[中国非遗网·布依族服饰](https://www.ihchina.cn/project_details/15328/)
- 五个导游道具由 Codex 为本项目绘制。原创 SVG、PNG 与动作 CSS 随本仓库提交，供本项目使用、修改和分发。
- 贵州九市州区划提取自 OpenStreetMap 贵州省关系的九个地级子关系。采用 2026 年 11 月获取的 WGS84 边界，将共享边界分段一起简化后形成 `data/guizhou-prefectures.json`，各 feature 记录原关系 ID。数据为 ODbL 1.0，由 OpenStreetMap 贡献者提供。[贵州省 OpenStreetMap 关系](https://www.openstreetmap.org/relation/286937) · [署名与许可](https://www.openstreetmap.org/copyright)
- 两个梵净山入口的位置出处登记在景点目录。地图按经纬度显示景点的近似位置。
